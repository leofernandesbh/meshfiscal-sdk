# Changelog

## 0.1.0 — candidato F20

Pacote inicial MIT preparado, ainda não publicado. Contrato público `/v1`, OpenAPI 3.0.3; servidor 0.1.0. API key, access token e OAuth2 Client Credentials single-flight; timeout/abort, UUIDv7, retries opt-in de leituras, idempotência, espera com backoff, cursores limitados, verificação de webhook, helpers NF-e/DF-e e streaming íntegro de artefatos. Tipos gerados incluem NFC-e e NFS-e Nacional, sem engine fiscal.

ESM/CJS e declarations condicionais; guard server-side para browser/renderer/mobile; pacote allowlist, consumidor real e preparação OIDC/provenance. Nenhuma deprecação nesta versão. Changesets registram incrementos subsequentes; publicação real e provenance dependem do fluxo autorizado descrito no runbook de release.
